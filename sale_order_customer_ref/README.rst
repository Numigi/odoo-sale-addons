=============================
Sale Order Customer Reference
=============================
This module adds `Customer Reference` (client_oder_ref) in the following list views accessible with the menus :

*Sales > Orders > Quotations*

.. image:: https://raw.githubusercontent.com/Numigi/odoo-sale-addons/14.0/sale_order_customer_ref/static/description/quotations_list.png

*Sales > Orders > Orders*

.. image:: https://raw.githubusercontent.com/Numigi/odoo-sale-addons/14.0/sale_order_customer_ref/static/description/orders_list.png

*Sales > To Invoice > Orders to Invoice*

.. image:: https://raw.githubusercontent.com/Numigi/odoo-sale-addons/14.0/sale_order_customer_ref/static/description/orders_to_invoice_list.png

*Sales > To Invoice > Orders to Upsell*

.. image:: https://raw.githubusercontent.com/Numigi/odoo-sale-addons/14.0/sale_order_customer_ref/static/description/orders_to_upsell_list.png

NOTICE
------
For each list view, the `Customer Reference` (client_order_ref) could be hidden optionally.

.. image:: https://raw.githubusercontent.com/Numigi/odoo-sale-addons/14.0/sale_order_customer_ref/static/description/column_to_display_option.png

And for all these tree views, it is possible to search by `Customer Reference` (client_order_ref).

.. image:: https://raw.githubusercontent.com/Numigi/odoo-sale-addons/14.0/sale_order_customer_ref/static/description/search_with_client_order_ref.png
